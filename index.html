Building philosophies

  • How you do anything is how you do everything. Be intentional and be thoughtful.
  • Simplicity is a competitive advantage. The complicated is common; the awesomely simple is rare.
  • The work reveals itself through iteration. Ship, watch, cut, repeat. Quality emerges from selection, not perfection.
  • White space is where the real work happens. Great ideas don't come from meetings or dashboards, they emerge in reflection.
  • The urgent destroys the important. Continually seek out the signal within the noise.
  • Build at a system level"You do not rise to the level of your goals, you fall to the level of your systems."
  • Seek disagreement from smart people. You have two ears and one mouth — use them proportionally.
  • Be endlessly curiousCuriosity can close the gap with expertise.

  • Marketing Claims Analyzer Chrome extension2026

    A browser extension that brings AI-powered transparency to online shopping. Built with a privacy-first architecture: BYOK via OpenAI or Claude, no data collection, no tracking.

    • Works on Amazon, Shopify, and any product page
    • Verdicts: Supported · Misleading · Unverified
    • Product-aware: builds ingredient context before drawing conclusions
    • BYOK via OpenAI or Claude — no data collection, no tracking
    • Fraction of a penny per analysis

    Chrome Web Store · GitHub

  • FPL Transfer Analyzer Web app2025

    A web app that gives Fantasy Premier League managers mathematically optimal transfer recommendations. Enter your team ID and it pulls your squad from the official FPL API, then solves a Mixed Integer Linear Program to maximize expected points over the next three gameweeks — accounting for budget, squad composition, club limits, selling prices, and the -4 hit for extra transfers.

    • MILP solver via PuLP + HiGHS
    • Live squad data from the official FPL API
    • Next.js 15 · TypeScript · Tailwind CSS frontend
    • Python optimizer called via Next.js API routes
    • Deployed on Vercel with on-demand Python execution
